# Business Analyst A11y

Use this skill to convert technical accessibility findings into delivery-ready business analysis output.

## Core output

For each finding, produce:
- As-Is state
- user and business impact
- To-Be state
- developer action
- BA action
- PO action
- owner placeholder
- ETA placeholder

## Analysis lens

- Clarify current journey breakdown points.
- Map impact to user segment and task completion.
- Tie each issue to acceptance criteria and release scope.
- Remove ambiguity so implementation can be estimated and prioritized.

## Report contract

When paired with persona audits, ensure all findings are understandable by:
- developer
- business analyst
- product owner
